# 水韵江苏 · Jiangsu Cultural Journey

Bilingual digital cultural guide MVP for international students.

## Current phase

Phase 1 is implemented: design system and homepage foundation.

- React + TypeScript + Vite
- Tailwind CSS and shadcn/ui-style primitives
- React Router
- Framer Motion with reduced-motion support
- Accurate public GeoJSON base for Jiangsu's 13 prefecture-level cities
- Local bilingual language state
- One-time ShuiLing welcome layer using `localStorage`
- Responsive navigation, theme explorer, 404 page and accessibility basics

The full City data model, city pages, ShuiLing media, local knowledge demo and RAG service layer
belong to later user-approved phases.

## Commands

```bash
npm install
npm run dev
npm run test
npm run build
```
