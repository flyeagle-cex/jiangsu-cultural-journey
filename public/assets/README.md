# Asset provenance

The phase-one homepage images were extracted from the Word research files supplied in
`新文化大赛/江苏十三市文化资料库`. They remain local to this project and were converted to
web-friendly JPEG copies without modifying the source documents.

- `hero-grand-canal.jpg`: Yangzhou research file, embedded `image5.png`
- `theme-grand-canal.jpeg`: Nanjing research file, embedded `image1.jpeg`
- `theme-nature.jpg`: Lianyungang research file, embedded `image2.png`
- `theme-history.jpeg`: Nanjing research file, embedded `image4.jpeg`
- `theme-heritage.jpg`: Yangzhou research file, embedded `image6.png`
- `theme-food.jpg`: Yangzhou research file, embedded `image7.png`

The Canva whiteboard `DAHR-SLviJ0` is connected as the preferred source for future ShuiLing
character and video media. Its original image/video assets were not exportable through the
read-only connector during phase one, so the code uses an explicit `data-asset-slot` placeholder
instead of fabricating a character image.
